桶装水配送系统 - 一键部署说明
====================================

服务器: 43.138.207.105

最简单的部署方法（只需要3个命令）
====================================

第1步: 连接到服务器
--------------------
ssh root@43.138.207.105
输入密码后按回车

第2步: 创建并运行部署脚本
--------------------
复制下面的完整脚本内容，在服务器上执行:

cat > deploy.sh << 'DEPLOY_SCRIPT'
#!/bin/bash
set -e

echo "=========================================="
echo "  桶装水配送系统 - 一键部署"
echo "=========================================="

# 更新系统
echo "[1/10] 更新系统..."
apt update && apt upgrade -y > /dev/null 2>&1

# 安装基础工具
echo "[2/10] 安装基础工具..."
apt install -y git curl wget vim net-tools unzip ufw software-properties-common > /dev/null 2>&1

# 安装Node.js
echo "[3/10] 安装Node.js..."
if ! command -v node &> /dev/null; then
    curl -fsSL https://deb.nodesource.com/setup_18.x | bash - > /dev/null 2>&1
    apt install -y nodejs > /dev/null 2>&1
fi

# 安装Docker
echo "[4/10] 安装Docker..."
if ! command -v docker &> /dev/null; then
    curl -fsSL https://get.docker.com | sh > /dev/null 2>&1
    usermod -aG docker $USER
fi

# 安装Docker Compose
echo "[5/10] 安装Docker Compose..."
if ! command -v docker-compose &> /dev/null; then
    curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose 2>/dev/null
    chmod +x /usr/local/bin/docker-compose
fi

# 安装PM2
echo "[6/10] 安装PM2..."
if ! command -v pm2 &> /dev/null; then
    npm install -g pm2 > /dev/null 2>&1
fi

# 安装Nginx
echo "[7/10] 安装Nginx..."
if ! command -v nginx &> /dev/null; then
    apt install -y nginx > /dev/null 2>&1
    systemctl stop nginx > /dev/null 2>&1
    systemctl disable nginx > /dev/null 2>&1
fi

# 配置防火墙
echo "[8/10] 配置防火墙..."
ufw --force enable > /dev/null 2>&1
ufw allow 22/tcp > /dev/null 2>&1
ufw allow 80/tcp > /dev/null 2>&1
ufw allow 443/tcp > /dev/null 2>&1
ufw allow 3001/tcp > /dev/null 2>&1

# 配置时区
echo "[9/10] 配置时区..."
timedatectl set-timezone Asia/Shanghai > /dev/null 2>&1

# 创建项目目录
echo "[10/10] 创建项目目录..."
mkdir -p ~/water-delivery
mkdir -p ~/backups
mkdir -p ~/logs

echo ""
echo "=========================================="
echo "  安装完成！"
echo "=========================================="
echo ""
echo "已安装软件:"
node -v 2>/dev/null || echo "  Node.js: 未安装"
npm -v 2>/dev/null || echo "  npm: 未安装"
docker --version 2>/dev/null || echo "  Docker: 未安装"
docker-compose --version 2>/dev/null || echo "  Docker Compose: 未安装"
pm2 -v 2>/dev/null || echo "  PM2: 未安装"
echo ""
echo "下一步: 上传项目代码到 ~/water-delivery 目录"
echo "=========================================="
DEPLOY_SCRIPT

chmod +x deploy.sh
./deploy.sh

第3步: 上传项目代码
--------------------
使用WinSCP或其他工具，将 water-delivery-new 文件夹上传到服务器的 ~/water-delivery 目录

然后在服务器上执行:
cd ~/water-delivery
mv water-delivery-new/* .
rm -rf water-delivery-new

第4步: 配置并启动
--------------------
cd ~/water-delivery

# 创建环境变量
mkdir -p prod
cat > prod/.env << 'EOF'
NODE_ENV=production
BACKEND_PORT=3001
API_KEY=water-delivery-$(openssl rand -hex 16)
DB_PATH=/app/data/database.db
LOG_LEVEL=info
LOG_PATH=/app/logs
VITE_API_URL=http://43.138.207.105/api
VITE_APP_TITLE=桶装水配送管理系统
VITE_DELIVERY_API_URL=http://43.138.207.105/api
VITE_DELIVERY_APP_TITLE=配送助手
NGINX_PORT=80
DOMAIN=43.138.207.105
DELIVERY_DOMAIN=43.138.207.105
EOF

# 构建前端
cd frontend
npm install
npm run build

# 启动服务
cd ~/water-delivery
docker-compose -f docker-compose.prod.yml build
docker-compose -f docker-compose.prod.yml up -d

完成！
